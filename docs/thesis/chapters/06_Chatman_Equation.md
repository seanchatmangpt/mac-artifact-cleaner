# Chapter 6: Chatman Equation

## 6.1 The Chatman Equation
The Universal Chatman Equation establishes the mathematical transition from raw observation to unforgeable process evidence:
$$A = \mu(O^*)$$
where:
* $O^*$ represents the raw, continuous observation stream of system states (e.g., directory structures, sizes, metadata).
* $\mu$ is the structured transformation mechanism (e.g., the parser and compiler adjudicator).
* $A$ is the discrete, unforgeable evidence (e.g., the typestate-admitted deletion plan and the cryptographic receipt).

## 6.2 Domain Generalization
This chapter demonstrates that the same mathematical equation that governs symbolic programming language structures (e.g., LSPs, ASTs) also applies to the local developer filesystem domain. We show how $\mu$ translates filesystem state directories into compliant object-centric event streams.
